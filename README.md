# Для прогулок

Кроссплатформенное приложение для пеших онлайн-экскурсий (iOS, Android, Web). Указываете старт и длительность или длину прогулки, а ИИ подбирает достопримечательности, строит маршрут по улицам и создаёт аудиорассказы.

## Возможности

- **Маршрут от ИИ.** Старт задаётся адресом, геолокацией или точкой на карте; длительность или длина и пожелания определяют подборку.
- **Город — первый выбор.** При первом запуске приложение спрашивает город (поиском, по геолокации или из списка городов с экскурсиями). Каталог показывает экскурсии этого города, а создание маршрута начинается в нём. Город меняется в каталоге.
- **Открытый каталог.** Маршруты можно публиковать; есть поиск, фильтр «Рядом», оценки от 1 до 5.
- **Ручная правка.** Автор добавляет места из подсказок рядом с маршрутом, поиском по адресу или нажатием на карту; новое место встаёт туда, где крюк меньше. Порядок точек меняется стрелками или кнопкой «Упорядочить автоматически», путь по улицам пересчитывается. Старт переносится (поиск, карта, геолокация), а финиш ставится у старта, на последней точке или в своём месте.
- **В навигатор.** Файлы GPX (OsmAnd, Organic Maps, Komoot, Garmin) и KML (Google Earth), пеший маршрут в Яндекс Картах и Google Картах (у Google не больше 9 промежуточных точек).
- **Материалы автора.** К точке можно прикрепить фото, видео и аудио.
- **Аудиорассказы.** ИИ (Claude или DeepSeek) пишет текст по статье Википедии, сервис озвучки делает mp3. Без него рассказ читает голос устройства.
- **Фото мест.** У точки — фото с Wikimedia Commons (заглавное фото статьи или изображение из Викиданных) с автором и лицензией.
- **Места без статьи в Википедии.** Объекты культурного наследия рядом берутся из Викиданных (у них есть номер реестра ЕГРОКН), а рассказ о них ИИ пишет по справке: год, архитектор, стиль, охранный статус, номер в реестре, данные из тегов OSM. Портал открытых данных Минкультуры недоступен с хостинга, поэтому данные реестра берутся из Викиданных и OSM (`ref:okn`).
- **Готовые рассказы переиспользуются.** Если о месте уже есть рассказ в том же направлении и на том же языке, он берётся из другого маршрута вместе с озвучкой тем же голосом: без запросов к ИИ и синтеза. Тексты, написанные автором, не переиспользуются; «Создать заново» всегда пишет новый текст.
- **Поделиться.** Ссылка на маршрут отправляется в Telegram, WhatsApp, ВКонтакте или через системное меню; в мессенджере показывается превью с названием, длиной и фото. Приватный маршрут сначала нужно открыть.
- **Подтверждение почты и лимит.** С подключённой почтой (`SMTP_URL`) создавать и публиковать маршруты и ставить оценки можно только после перехода по ссылке из письма. Пользователь создаёт до 5 маршрутов в календарный месяц (`ROUTE_MONTHLY_LIMIT`); удаление маршрута лимит не возвращает, правка существующих не ограничена.
- **Факты или легенды.** Для маршрута выбирается направление рассказов: «Факты» (история места) или «Мифы и легенды» (предания и поверья из раздела статьи о легендах; ИИ помечает их как легенды и не сочиняет новых). Направление можно сменить и пересоздать рассказы.

## Запуск

Нужен Node.js 24 или новее.

```bash
cd server && npm install && cp .env.example .env   # заполните ключи
npm run dev                                        # http://localhost:3000

cd app && npm install
npx expo start                                     # w — веб, i/a — симулятор, QR — телефон
```

На телефоне приложение обращается к серверу на том же компьютере, где запущен Expo. Для другого адреса задайте `EXPO_PUBLIC_API_URL`.

### Ключи

| Переменная | Для чего | Что будет без неё |
|---|---|---|
| `ANTHROPIC_API_KEY` или `DEEPSEEK_API_KEY` | Подбор мест и тексты рассказов | Подбор по рейтингу мест, рассказ — выдержка из Википедии |
| `YANDEX_API_KEY`, `TTS_BASE_URL` или `TTS_API_KEY` | Озвучка в mp3: Yandex SpeechKit, свой контейнер Piper или OpenAI-совместимый сервис | Рассказ читает голос устройства |

Приложение каждый раз сообщает, если ИИ был недоступен и сработал запасной вариант.

### Озвучка в контейнере

Русская озвучка на [Piper](https://github.com/OHF-Voice/piper1-gpl), голоса `denis` и `dmitri` (датасеты под CC0):

```bash
docker compose up -d tts                 # из корня проекта, первая сборка ~1 мин, образ ~850 МБ
```

В `server/.env`: `TTS_BASE_URL=http://localhost:8880/v1` и `TTS_VOICE=denis`. Контейнер слушает только localhost и работает без ключа. Если он будет доступен из сети, задайте `API_KEY` в `docker-compose.yml` и такой же `TTS_API_KEY` на сервере.

Kokoro не подошёл: русского языка в нём нет.

### Озвучка в Yandex SpeechKit

Yandex AI Studio, SpeechKit API v3, стандартные голоса, mp3 с нормализацией громкости LUFS: те же параметры, что у Python-SDK `sdk.speechkit.text_to_speech(...)`. Нужен API-ключ сервисного аккаунта с ролью `ai.speechkit-tts.user`:

```bash
YANDEX_API_KEY=...
YANDEX_FOLDER_ID=...         # необязательно
YANDEX_TTS_VOICE=alexander   # alena, filipp, ermil, jane, dasha, julia, kirill, anton и др.
YANDEX_TTS_ROLE=good         # амплуа, у каждого голоса свой набор
YANDEX_TTS_SPEED=1
YANDEX_TTS_PITCH=0
```

Если задан ключ, SpeechKit важнее Piper; `TTS_PROVIDER=openai` возвращает Piper или облачный сервис. Длинный текст режется на части по 4800 символов по границам предложений. Тексты рассказов при этом уходят в Yandex Cloud.

### Выбор ИИ

Модель выбирается на сервере, для всех пользователей сразу. Достаточно задать один ключ. Если заданы оба, работает Claude, а `AI_PROVIDER` меняет выбор:

```bash
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=...
DEEPSEEK_MODEL=deepseek-flash   # по умолчанию; также есть deepseek-v4-pro
```

Если `AI_PROVIDER` задан с ошибкой или без ключа, сервер не запустится и назовёт причину. При смене провайдера стартовая точка и пожелания пользователя уходят в сервис этого провайдера: учтите это в политике конфиденциальности.

## Устройство

```
app/     Expo Router + React Native Web. Один код на три платформы
server/  Fastify + SQLite (node:sqlite). Запускается без сборки
  src/planner.ts   кандидаты → отбор → порядок обхода → подгонка под бюджет
  src/services.ts  Википедия, Overpass (OSM), OSRM, Nominatim
  src/ai.ts        общие промпты и интерфейс ИИ
  src/ai-claude.ts, ai-deepseek.ts  адаптеры моделей
  src/ai-provider.ts  выбор модели по окружению
  src/tts.ts       озвучка: Yandex SpeechKit или OpenAI-совместимый API
  src/places.ts    фото с Commons, справка из Викиданных, объекты реестра наследия
  src/mail.ts      письма подтверждения почты (SMTP)
  src/share.ts     превью ссылок для мессенджеров
tts/     контейнер озвучки на Piper
  public/          страница карты на Leaflet (iframe на вебе, WebView на телефонах)
```

ИИ выбирает только из реальных объектов, найденных рядом: id проверяются сервером, а порядок обхода и длину считает код. Так модель не может придумать несуществующее место или нарушить бюджет прогулки.

## Перед продакшеном

- **Карта.** Публичные `tile.openstreetmap.org`, `routing.openstreetmap.de`, Nominatim и Overpass не рассчитаны на нагрузку от приложений. Нужны свои сервисы или платный провайдер (`MAP_TILE_URL` для тайлов; адреса маршрутизации и геокодера заданы в `server/src/services.ts`).
- **HTTPS.** Сервер должен работать за обратным прокси с TLS: сборки iOS и Android не ходят на незащищённый HTTP.
- **Хранилище.** Загрузки лежат на локальном диске, файлы приватных маршрутов защищены только случайным именем. Для нескольких серверов нужно S3-совместимое хранилище и общая БД.
- **Модерация.** Публичные маршруты и загрузки никто не проверяет: нужны жалобы и модерация, этого требуют App Store и Google Play. Там же обязательно удаление аккаунта, его пока нет.
- **Сброс пароля** пока не реализован. Подтверждение почты работает, если задан `SMTP_URL`.
- **Сторонний контент.** Тексты из Википедии распространяются по CC BY-SA, в приложении показывается ссылка на источник.
